# generic_array_data: the base theme

The genetic_anomaly template, duplicated with the most generic word for everything (thing,
group, place, side, level). Every theme sits on this base: a theme only holds what it changes.
In the prototype, **G** swaps a game's words back to these and **Tab** collapses the whole game
into a spreadsheet (columns from `game_sheet/game_sheet_columns`).
